# Prepositioner: valmatris

> 🧠 **Mental model — choose the relation first:** ask what kind of relation you need: time, place, direction, reason, purpose, means, topic, comparison, or belonging. Then pick the preposition that matches that relation instead of translating word for word.

## Quick matrix

| Situation | Ask yourself | Use | Example |
|---|---|---|---|
| Exact day / named time point | Is it a specific point on the calendar? | **på** | **på** måndag, **på** morgonen |
| Within a period / duration | Is it inside a time span? | **i** | **i** somras, **i** två timmar |
| Future / recurring time | Is it a future or repeated time idea? | **om** | **om** en vecka, **om** sommaren |
| Ago / back from now | Is it counting backward from now? | **för ... sedan** | **för** två år **sedan** |
| Inside a container / country / abstract area | Is something inside a space or domain? | **i** | **i** huset, **i** Sverige |
| On a surface / at an event | Is it on top of a surface or at a public activity? | **på** | **på** bordet, **på** jobbet |
| Next to / by / near | Is it close to something? | **vid** | **vid** sjön, **vid** disken |
| At a person or service | Is it at someone’s place or with a provider? | **hos** | **hos** mig, **hos** doktorn |
| Destination / recipient | Is something moving toward a goal or person? | **till** | **till** skolan, **till** Anna |
| Toward but not necessarily arriving | Is it moving in the direction of something? | **mot** | **mot** centrum, **mot** oss |
| Origin / source / material | Does it come from something or is it made of it? | **från** / **av** | **från** jobbet, ett hus **av** trä |
| Cause / reason | Is it explaining why something happened? | **av** / **på grund av** | **av** rädsla, **på grund av** regnet |
| Purpose / benefit | Is it explaining what something is for? | **för** | en bok **för** Anna, **för** att spara tid |
| Companion / instrument | Is it the thing you use or go with? | **med** | **med** buss, **med** en penna |
| Without something | Is something absent? | **utan** | **utan** kaffe, **utan** hjälp |
| Through a path / method | Is something passing through a channel or method? | **genom** | **genom** dörren, **genom** att öva |
| Via a route or channel | Is it a route or medium? | **via** | **via** mejl |
| About a topic | Is it the thing you are talking about? | **om** | en bok **om** Sverige |
| Broader or approximate topic | Is it a looser “around/concerning” relation? | **kring** | **kring** problemet |
| Comparison | Is it the benchmark for a comparison? | **än** | större **än** jag |
| Rate / each unit | Is it distributed per unit? | **per** | 50 kronor **per** person |
| Inside a group | Is it located among a set of people or things? | **bland** | populär **bland** ungdomar |

## Fast decision flow

1. If it is about **time**, start with **på**, **i**, **om**, or **för ... sedan**.
2. If it is about **space**, start with **i**, **på**, **vid**, or **hos**.
3. If it is about **movement**, start with **till**, **mot**, or **från**.
4. If it is about **reason or purpose**, start with **av**, **på grund av**, or **för**.
5. If it is about **means or method**, start with **med**, **utan**, **genom**, or **via**.
6. If it is about **topic, comparison, or quantity**, start with **om**, **kring**, **än**, **per**, or **bland**.

## Mini reminder

The same word can appear in more than one row because Swedish prepositions are relational, not one-to-one translations. The safest question is always: **what relation does this phrase express?**
