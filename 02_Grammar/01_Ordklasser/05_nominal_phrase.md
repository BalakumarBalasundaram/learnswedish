
# Swedish Nominal Phrase – Master Pattern Exercise

## Introduction: The Master Pattern

This exercise trains the **core Swedish nominal phrase system**.
For every noun, practice the following transformation path:

1. **Indefinite singular**  
2. **Indefinite singular + adjective**  
3. **Definite singular**  
4. **Definite singular + adjective**  
5. **Indefinite plural**  
6. **Indefinite plural + adjective**  
7. **Definite plural**  
8. **Definite plural + adjective**

### Universal rules to remember
- **en/ett** depends on the noun
- **Plural → adjective ends in -a**
- **Definite + adjective → den / det / de**
- **Plural definite → -na / -en on the noun**

### Example patterns

**EN-word (bok):**  
en bok → boken → den stora boken → böcker → böckerna → de stora böckerna

**ETT-word (barn):**  
ett barn → barnet → det lilla barnet → barn → barnen → de små barnen
