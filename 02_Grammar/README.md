# Grammatik (Grammar)

> 🧠 **Mental model — building a house:** 01 Ordklasser = the bricks (the words themselves), 02 Verb = the engine room (actions and time), 03 Ordföljd = the traffic rules (where everything is allowed to stand), 04 Prepositioner = the doors and windows (how things relate in space/time), 05 Satslära = the wiring connecting every room into one house (clauses joined into text), 06 Adjektiv = the paint and texture on every wall (describing nouns), 07 Adverb = the dimmer switches (describing how/when/where an action happens).

## Recommended Study Path (step-by-step)

The 7 folders below are grouped **by topic** (good for lookup/reference), not by difficulty. If you want a strict step-by-step order instead, follow this numbered path — it jumps between folders but always moves from easiest → hardest.

> **Teaching order note:** sentence structure and connectors are placed at the end of the sequence, after the learner understands the core word classes, verb patterns, predicate, and adverb behavior. This makes Satslära a final synthesis layer rather than an early starting point.

```
A1 → A2 → B1 → B2
easiest ─────────────────────────────────▶ hardest
```
