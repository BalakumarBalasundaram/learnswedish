# Satsbyggnad: koppla samman till en paragraf

> 🧠 **Mental model — sentences become paragraphs when clauses start talking to each other:** one sentence gives the point, the next sentence extends it, explains it, or contrasts it. Paragraphs are built with the same tools as sentences, just with more repetition and clearer connection.

## How paragraph depth is built

A good paragraph usually does one of these things:

- repeats the key topic in a new way
- adds an example
- explains the reason
- contrasts one idea with another
- concludes with a summary

## Tools that help

- **Konjunktioner** join clauses at the same level.
- **Subjunktioner** create dependent clauses.
- **Relativa pronomen** attach extra information to a noun.
- **Textbindning** keeps the flow clear across multiple sentences.

## Simple pattern

**point → explanation → example → consequence**

## Example paragraph chain

- **Jag lär mig svenska.**
- **Det hjälper mig i jobbet.**
- **Därför övar jag varje dag.**
- **På så sätt blir jag säkrare när jag skriver längre texter.**

## Mini reminder

If a sentence is the brick, then a paragraph is the wall. You build the wall by keeping the same topic alive while changing the angle.
