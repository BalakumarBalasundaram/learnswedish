# Satsbyggnad: satsens grund

> 🧠 **Mental model — one sentence, one engine:** every sentence needs a core engine: subject + verb + clause type. If that engine is unclear, the rest of the sentence cannot be built reliably.

## What this page covers

This is the starting point for sentence building. It focuses on the pieces that must exist before any extra detail can be attached:

- who or what the sentence is about
- what happens or what state exists
- whether the clause is a huvudsats or bisats
- what the basic verb frame looks like

## Core pattern

A useful order is:

**subject → verb → object → adverbials**

That order is only the starting point. Swedish then modifies it depending on clause type, focus, and whether the sentence contains a fronted element, a question word, or a subordinate connector.

## Main questions

Ask these first:

- Who is the subject?
- What is the verb?
- Is the sentence a statement, question, or subordinate clause?
- Does the verb need an object?
- Does the sentence already contain a time, place, or direction phrase?

## Examples

- **Jag läser.**
- **Barnet sover.**
- **Vi äter middag.**
- **Hon skriver ett brev.**
