# 🌍 Core Swedish Prepositions + What They Do with Verbs

Below is a detailed explanation of Swedish prepositions and their effects when combined with verbs. Prepositions are grouped by their primary focus.

---

## 🧭 1. POSITION / PLACE Prepositions
These prepositions describe location, position, or state.

| **Preposition** | **English**       | **Verb Combination Clue**                  |
|-----------------|-------------------|--------------------------------------------|
| **i**          | in                | state / inside action → *vara i*, *gå in* |
| **på**         | on                | surface / activity → *sitta på*, *hålla på* |
| **under**      | under             | hidden / below state → *ligga under*      |
| **över**       | over              | movement across / excess → *gå över*      |
| **mellan**     | between           | relation / comparison → *välja mellan*    |
| **vid**        | by / at           | position near → *stå vid*                 |
| **hos**        | at someone’s place| social location → *vara hos*              |
| **inom**       | within            | limit boundary → *ske inom*               |
| **utanför**    | outside           | external position → *stå utanför*         |

### 👉 Pattern:
- **vara + prep** = state
- **gå + prep** = movement

---

## 🚀 2. DIRECTION / MOVEMENT Prepositions
These prepositions indicate movement, direction, or change.

| **Preposition** | **English** | **Verb Effect**                          |
|-----------------|-------------|------------------------------------------|
| **till**       | to          | goal / destination → *gå till*          |
| **från**       | from        | origin → *komma från*                   |
| **mot**        | towards     | direction (not reached) → *gå mot*      |
| **genom**      | through     | process / passing → *gå genom*          |
| **in**         | into        | enter / start state → *gå in*           |
| **ut**         | out         | exit / finish → *gå ut*                 |
| **upp**        | up          | increase / completion → *äta upp*       |
| **ner**        | down        | decrease / lowering → *gå ner*          |

### 👉 Magic Insight:
- **in / ut / upp / ner**: These often change the verb meaning completely. These are particle verbs, not just location!

---

## ⚡ 3. TIME Prepositions
These prepositions relate to time and temporal connections.

| **Preposition** | **English** | **Verb Clue**                           |
|-----------------|-------------|-----------------------------------------|
| **före**       | before      | earlier action → *före börja*          |
| **efter**      | after       | result / later → *efter jobba*         |
| **under**      | during      | ongoing period → *under mötet*         |
| **inom**       | within      | deadline → *göra inom en vecka*        |
| **sedan**      | since       | time connection → *sedan dess*         |

---

## 🤝 4. RELATION / ABSTRACT Prepositions
These prepositions describe relationships, purposes, or abstract connections.

| **Preposition** | **English** | **Verb Structure Meaning**              |
|-----------------|-------------|-----------------------------------------|
| **för**        | for         | purpose / benefit → *göra för*         |
| **av**         | of / by     | source / passive agent → *gjort av*    |
| **med**        | with        | tool / company → *skriva med*          |
| **utan**       | without     | absence → *leva utan*                  |
