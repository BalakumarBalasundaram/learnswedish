# 🚀 Base Verb + Modal Verbs

## SKRIVA (to write)
**Base Verb**: skriva
- **Modal Verbs**:
  - **kan skriva**: Jag kan skriva en bok (*I can write a book*).
  - **måste skriva**: Jag måste skriva en bok (*I must write a book*).
  - **ska skriva**: Jag ska skriva en bok (*I will write a book*).
  - **bör skriva**: Jag bör skriva en bok (*I should write a book*).

## SLUTA (to stop)
**Base Verb**: sluta
- **Modal Verbs**:
  - **kan sluta**: Jag kan sluta nu (*I can stop now*).
  - **måste sluta**: Jag måste sluta nu (*I must stop now*).
  - **ska sluta**: Jag ska sluta snart (*I will stop soon*).
  - **bör sluta**: Jag bör sluta röka (*I should stop smoking*).

## BEDÖMA (to judge)
**Base Verb**: bedöma
- **Modal Verbs**:
  - **kan bedöma**: Jag kan bedöma situationen (*I can judge the situation*).
  - **måste bedöma**: Jag måste bedöma det noggrant (*I must judge it carefully*).
  - **ska bedöma**: Jag ska bedöma det imorgon (*I will judge it tomorrow*).
  - **bör bedöma**: Jag bör bedöma alla fakta (*I should judge all the facts*).
