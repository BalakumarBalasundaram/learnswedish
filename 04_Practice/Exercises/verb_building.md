# 📘 Swedish Verb System: SKRIVA (to write)

> 🧠 **Mental model — home base + satellite meanings:** treat every verb like "skriva" as a home base, with particles as direction arrows docking satellite meanings onto it. Instead of memorizing each particle-verb separately, always ask "where does the core meaning go?" — upp (becomes visible), ut (goes out), in (goes into), ner (gets stored/fixed) — and the meaning derives itself.

---

## 🧭 1. Core Meaning

**skriva = to write**

- Base action: produce text / information
- Neutral verb (no direction yet)

---

## 🔧 2. Verb + Particle System

| Verbform | Partikel | Pattern (SV) | Meaning (EN) | Direction Logic |
|----------|----------|-------------|--------------|----------------|
| skriva | – | skriva text | write | neutral |
| skriva upp | upp ⬆️ | göra synligt | write down / record | → visible/result |
| skriva ut | ut 🚪 | ut från system | print | → out |
| skriva in | in 📦 | in i system | enter data | → into |
| skriva ner | ner ⬇️ | lagra / fixa | write down carefully | → store/fix |

---

## 🧠 3. Core Rule

👉 Always ask:

**“Where does the information go?”**

| Particle | Direction |
|----------|----------|
| upp | becomes visible |
| ut | goes out (digital → physical) |
| in | goes into system |
| ner | stored / fixed |

---

## 📊 4. Sentence Examples (Basic → Advanced)

### 🔵 A. Basic (SFI C)

- Jag skriver upp det nu  
- Hon skriver ut dokumentet  
- Vi skriver in namnet  

---

### 🟡 B. With time, place, demonstratives

- Jag skriver upp det här ordet nu  
- Hon skriver ut det där dokumentet idag  
- Vi skriver in våra namn där  

---

### 🟢 C. With bisats (subordinate clause)

- När jag hör något viktigt, skriver jag upp det  
- Eftersom hon behöver det, skriver hon ut dokumentet  

---

### 🔴 D. Advanced (complex sentence)

- När jag sitter där nu, skriver jag upp det som läraren säger, eftersom det är viktigt  

---

## 🧩 5. Sentence Pattern Variations

### Idea: “write something down”

| Pattern | Example |
|--------|--------|
| Basic | Jag skriver upp det |
| With object | Jag skriver upp svaret |
| Relative clause | Jag skriver upp det som är viktigt |
| Passive | Det skrivs upp nu |
| Question | Skriver du upp det nu? |

---

## ⏳ 6. Tense System

| Tense | Swedish | English |
|------|--------|--------|
| Presens | Jag skriver upp det | I write it down |
| Preteritum | Jag skrev upp det | I wrote it down |
| Perfekt | Jag har skrivit upp det | I have written it down |
| Pluskvamperfekt | Jag hade skrivit upp det | I had written it down |
| Futurum | Jag ska skriva upp det | I will write it down |

---

## 🔄 7. Functional Meaning Map

- skriva upp → organize / record information  
- skriva ut → export information  
- skriva in → input information  
- skriva ner → store information  

---

## 🎭 8. Real-life Scenario

- Läraren säger något viktigt  
- Jag skriver upp det direkt  
- Sedan skriver jag in det i datorn  
- Efter det skriver jag ut dokumentet  
- Till slut skriver jag ner allt i min bok  

---

## 🧠 9. Word Network Sentence

Jag skriver upp, skriver ner, skriver in och skriver ut den här informationen nu, eftersom jag inte vill glömma, tappa bort, ignorera eller missa det som är viktigt där  

(I write down, record, enter and print this information now because I do not want to forget, lose, ignore or miss what is important there)

---

## 🚀 10. Learning Strategy

For every new verb:

1. Identify base verb  
2. Add particle meaning  
3. Ask: direction or result?  
4. Build sentence patterns  
5. Practice across tenses
