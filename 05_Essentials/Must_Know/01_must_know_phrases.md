# Must Know

> 🧠 **Mental model — the 5 verbs that unlock everything:** vara (be), ha (have), göra (do), vilja (want), kunna (can). Once these are automatic, you can build most beginner sentences by slotting a noun or infinitive after them.

## 1. The 5 Core Verbs (present tense)

| Svenska | English | Example | Translation |
|---|---|---|---|
| är (vara) | am/is/are | Jag är trött. | I am tired. |
| har (ha) | have/has | Jag har en bil. | I have a car. |
| gör (göra) | do/does | Vad gör du? | What are you doing? |
| vill (vilja) | want | Jag vill äta. | I want to eat. |
| kan (kunna) | can | Kan du hjälpa mig? | Can you help me? |

## 2. Question Words (frågeord)

| Svenska | English |
|---|---|
| vad | what |
| vem | who |
| var | where |
| när | when |
| varför | why |
| hur | how |
| vilken / vilket / vilka | which (en/ett/plural) |
| hur mycket / hur många | how much / how many |

| Example question | Translation |
|---|---|
| Vad heter du? | What's your name? |
| Var bor du? | Where do you live? |
| När öppnar butiken? | When does the shop open? |
| Hur mycket kostar det? | How much does it cost? |

## 4. Everyday Expressions

| Svenska | English |
|---|---|
| Jag vet inte. | I don't know. |
| Det spelar ingen roll. | It doesn't matter. |
| Det är okej. | It's okay. |
| Ingen fara. | No worries. |
| Absolut! / Självklart! | Absolutely! / Of course! |
| Jag tror det. / Jag tror inte det. | I think so. / I don't think so. |
| Vi får se. | We'll see. |
| Det beror på. | It depends. |

## 5. Negation & Time Markers

| Svenska | English |
|---|---|
| inte | not |
| aldrig | never |
| alltid | always |
| ofta | often |
| ibland | sometimes |
| snart | soon |
| redan | already |
| fortfarande | still |

## 6. Sample Sentences Combining the Above

| Svenska | English |
|---|---|
| Jag vill inte gå ut idag för att det regnar. | I don't want to go out today because it's raining. |
| Kan du säga var busshållplatsen är? | Can you tell me where the bus stop is? |
| Jag har alltid velat lära mig svenska. | I have always wanted to learn Swedish. |
| Det beror på hur mycket tid du har. | It depends on how much time you have. |

## Practice
- Drill the 5 core verbs with different subjects (jag/du/han/vi/de) until automatic.
- Turn each question word into 3 of your own questions.
