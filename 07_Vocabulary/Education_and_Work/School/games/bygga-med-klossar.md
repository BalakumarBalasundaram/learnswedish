# Bygga med klossar

## Swedish
Bygga med klossar är en kreativ lek där barn bygger torn, hus eller andra former med klossar.

## English
Building with blocks is a creative game where children build towers, houses, or other shapes with blocks.

## How to play
- Barnen tar klossar.
- De bygger höga torn eller små hus.
- De kan arbeta tillsammans eller individuellt.
- De visar sina byggnader för varandra.

## Useful words
- kloss = block
- bygga = to build
- torn = tower
- hus = house
- form = shape

## Example sentence
- Vi bygger ett högt torn med klossar.  
  We build a tall tower with blocks.
