# Learn Swedish — Layered Study System

A cross-skill learning library, structured the same way as a technical deep-dive wiki: each **session** (numbered folder) plays a distinct role in one connected model, sub-sessions go from foundational to applied, and everything ultimately feeds a single **11-layer per-word study engine** defined in [01_Patterns](01_Patterns/readme.md).

File naming follows the `{session}_{Category}/{sub}_{topic}.md` convention — mirroring the `s{session}.{sub}-{DOMAIN}` scheme used in the mathematics cross-skill wiki.

## Which folder does new content belong in? (01 vs. 05 vs. 06 vs. 07 vs. 08)

Sessions 01, 05, 06, 07 and 08 all *involve* words and sentences, which makes them easy to confuse. What actually separates them is the **unit of content** each one stores — not the topic:

| Session | Unit of content | Format | Example |
|---|---|---|---|
| **01 Patterns** | *(no Swedish content — method only)* | System doc + 15 reusable clause templates | [readme.md](01_Patterns/readme.md) |
| **05 Essentials** | One fixed survival **phrase** | Short phrase list, no dialogue, no topic grouping | "Hej, jag heter…", "Var är toaletten?" |
| **06 Conversations** | A multi-turn **dialogue** | 2+ speakers, full script + line-by-line translation table | [01_bluey_familjesamtal.md](06_Conversations/Daily_Life/01_bluey_familjesamtal.md) |
| **07 Vocabulary** | One **word/term**, grouped by topic domain | Word bank / word list, feeds the Patterns "Related Word Network" layer | [Mindmap.md](07_Vocabulary/Mindmap.md) domain folders |
| **08 Situations** | A **cluster of terms along one real-world axis** | Spectrum/comparison — each file explains one term's place relative to the others | [torr väg.md](08_Situations/Driving_Road_Conditions/torr%20väg.md) → våt → slaskig → snötäckt → vintergrus |

> 💡 **Rule of thumb when creating a new file:**
> 1. Is it a reusable *method/template*, not actual Swedish content? → **01 Patterns**.
> 2. Is it a single word, or a short list of words with no back-and-forth dialogue? → **07 Vocabulary**, nested under its topic domain.
> 3. Is it one fixed short phrase every absolute beginner must memorize on day 1, regardless of topic? → **05 Essentials**.
> 4. Is it a full back-and-forth conversation between two or more named speakers? → **06 Conversations**, nested under its life-domain (Daily_Life, Shopping, Social, Work).
> 5. Does it only make sense when compared against sibling terms along one real-world axis (severity, formality, time, weather...)? → **08 Situations**, one file per point on that axis.

## Layer Structure (per word, via 01_Patterns)

| Layer Range | Content |
|---|---|
| Layers 1–3 | Word identity, related word network (~20 words), multilingual (Svenska/English/Tamil) anchor |
| Layers 4–5 | Sentence-pattern integration + core grammar elements in context |
| Layers 6–7 | Verb system (tense, passive, reflexive, particle verbs) + extra grammar (negation, inversion, relative clauses) |
| Layers 8–9 | Text types (berättande, beskrivande, argumenterande…) + level progression (SFI C → SFI D → SVA 1 → 2 → 3) |
| Layers 10–11 | Real-life context (situation, time, register) + graded practice (easy → medium → advanced) |
