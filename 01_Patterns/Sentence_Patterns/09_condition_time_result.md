# 09 – Condition + time + result
**Pattern:** Huvudsats + bisats (om) + bisats (när) + huvudsats + passiv

```
■ HUVUDSATS ──▶ ▷ BISATS (om) ──▶ ▷ BISATS (när) ──▶ ■ HUVUDSATS ──▶ ▣ PASSIV
```

🧠 **Remember it as "if…when…(passively) done":** two gates (om, när) opening onto a passive result.

> **Vi kan gå ut** *om det slutar regna* *när rasten börjar*, **annars måste spelen spelas inomhus**.
> *(We can go outside if it stops raining when the break starts, otherwise the games must be played indoors.)*
