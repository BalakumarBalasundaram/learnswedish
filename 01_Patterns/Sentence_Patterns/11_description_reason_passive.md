# 11 – Description + reason + passive
**Pattern:** Huvudsats + relativsats + bisats (eftersom) + passiv bisats

```
■ HUVUDSATS ──▶ ◆ RELATIVSATS ──▶ ▷ BISATS (eftersom) ──▶ ▣ PASSIV BISATS
```

🧠 **Remember it as "that…because…was done":** describe it, explain why, then reveal it was made that way.

> **Boken** *som vi läser i klassen* **är intressant** *eftersom den skrevs av en känd författare*.
> *(The book that we read in class is interesting because it was written by a famous author.)*
