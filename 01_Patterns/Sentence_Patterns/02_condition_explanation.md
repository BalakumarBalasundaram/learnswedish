# 02 – Condition + explanation
**Pattern:** Huvudsats + bisats (om) + huvudsats + bisats (eftersom)

```
■ HUVUDSATS ──▶ ▷ BISATS (om) ──▶ ■ HUVUDSATS ──▶ ▷ BISATS (eftersom)
```

🧠 **Remember it as "if…but…because":** two logical hinges (om, eftersom) swinging off two main doors (huvudsats).

> **Du får högre betyg** *om du pluggar mer*, **men det är svårt** *eftersom provet är på fredag*.
> *(You'll get a higher grade if you study more, but it's hard because the test is on Friday.)*
