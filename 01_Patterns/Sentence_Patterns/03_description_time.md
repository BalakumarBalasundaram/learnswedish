# 03 – Description + time
**Pattern:** Huvudsats + relativsats + bisats (när) + huvudsats

```
■ HUVUDSATS ──▶ ◆ RELATIVSATS ──▶ ▷ BISATS (när) ──▶ ■ HUVUDSATS
```

🧠 **Remember it as "who…when":** describe the actor first (relativsats), then anchor the moment (bisats när).

> **Eleven** *som sitter längst bak* **räckte upp handen** *när läraren ställde en fråga*.
> *(The student who sits in the back raised their hand when the teacher asked a question.)*
