# 05 – Opinion + condition + result
**Pattern:** Huvudsats + att-sats + bisats (om) + bisats (utan att)

```
■ HUVUDSATS ──▶ ✦ ATT-SATS ──▶ ▷ BISATS (om) ──▶ ▷ BISATS (utan att)
```

🧠 **Remember it as "I think…if…without":** a belief wrapped around a condition and an exception.

> **Jag tror** *att man kan klara provet* *om man repeterar varje dag* *utan att stressa*.
> *(I think that you can pass the test if you review every day without stressing.)*
