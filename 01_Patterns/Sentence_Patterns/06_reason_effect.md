# 06 – Reason + effect
**Pattern:** Huvudsats + bisats (eftersom) + bisats (att) + passiv bisats

```
■ HUVUDSATS ──▶ ▷ BISATS (eftersom) ──▶ ▷ BISATS (att) ──▶ ▣ PASSIV BISATS
```

🧠 **Remember it as "because…that…is done":** a cause leading straight into a passive outcome.

> **Rektorn bestämde** *eftersom många elever var sjuka* *att lektionen* *skulle ställas in*.
> *(The principal decided, since many students were sick, that the lesson would be cancelled.)*
