# 13 – Opinion + description + limitation
**Pattern:** Huvudsats + att-sats + relativsats + bisats (utan att)

```
■ HUVUDSATS ──▶ ✦ ATT-SATS ──▶ ◆ RELATIVSATS ──▶ ▷ BISATS (utan att)
```

🧠 **Remember it as "I think…which…without":** an opinion, a description, and an exception.

> **Läraren sa** *att uppgiften* *som vi fick i måndags* **ska lämnas in** *utan att man använder internet*.
> *(The teacher said that the assignment that we got on Monday must be handed in without using the internet.)*
