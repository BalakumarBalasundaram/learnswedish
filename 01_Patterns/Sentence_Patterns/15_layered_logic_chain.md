# 15 – Layered logic chain
**Pattern:** Huvudsats + bisats (om) + bisats (eftersom) + att-sats + passiv

```
■ HUVUDSATS ──▶ ▷ BISATS (om) ──▶ ▷ BISATS (eftersom) ──▶ ✦ ATT-SATS ──▶ ▣ PASSIV
```

🧠 **Remember it as "if…because…that…is affected":** the deepest chain — condition → reason → belief → passive result.

> **Eleven kan få extra tid** *om hen frågar* *eftersom läraren vet* *att provet* **måste anpassas**.
> *(The student can get extra time if they ask, because the teacher knows that the test must be adapted.)*
