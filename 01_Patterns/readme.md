# Patterns – How to Study a Swedish Word

This system turns every new word into a complete learning unit.
Work through each section in order for one word at a time.

```
LAYER STACK (bottom → top = simple → applied)

 11 │ Practice ................. easy → medium → advanced drills
 10 │ Real-Life Context ........ situation · time · register
  9 │ Level Progression ........ SFI C → SFI D → SVA 1 → 2 → 3
  8 │ Text Types ............... berättande · beskrivande · argumenterande
  7 │ Additional Grammar ....... negation · inversion · relativsatser
  6 │ Verb System .............. tempus · passiv · reflexiv · partikelverb
  5 │ Grammar Elements ......... reference · demonstratives · time · particles
  4 │ Sentence Patterns ........ huvudsats/bisats combinations
  3 │ Multilingual Table ....... Svenska 🇸🇪 · English 🇬🇧 · Tamil 🇮🇳
  2 │ Related Word Network ..... ~20 connected words
  1 │ Word Identity ............ class · inflection · irregular forms
    └──────────────────────────────────────────────────────────────▶
                              ONE WORD
```

---

## 1. Word Identity

Identify the word's grammar and forms:

- **Word class** — substantiv, verb, adjektiv
- **Inflection**
  - Substantiv: en/ett, singular/plural, bestämd/obestämd
  - Adjektiv: en/ett/de + bestämd form
  - Verb: presens, preteritum, perfekt, pluskvamperfekt, futurum
- Note any irregular forms (especially verbs)

## 2. Related Word Network (~20 words)

Build a cluster of connected words:

- Synonymer (similar meaning)
- Antonymer (opposite meaning)
- Context words (nearby concepts)
- Partikelverb (particle verbs)
- Preposition combinations

## 3. Multilingual Table

| Svenska 🇸🇪 | English 🇬🇧 | Tamil 🇮🇳 |
|-------------|------------|-----------|
| ...         | ...        | ...       |

Helps memory through contrast and comparison.

---

## 4. Sentence Patterns

Practice the word in these clause structures:

- Huvudsats (main clause)
- Bisats + huvudsats
- Huvudsats + bisats
- Bisats + huvudsats + bisats ⭐ (advanced)
- Relativsats (den som, det som, de som)

## 5. Grammar Elements to Include in Examples

Every example sentence should cover a mix of:

| Category | Words / concepts |
|----------|-----------------|
| Reference words | det, detta, den, de, den som, de som, det är så |
| Demonstratives | den här / den där, det här / det där, de här / de där |
| Place & direction | här / där, hit / dit |
| Time | nu, då, idag, igår, senare |
| Modal particles | ju, väl, nog, visst, ändå, faktiskt |

## 6. Verb System

Use the word with different verb features:

- **Tenses** — presens, preteritum, perfekt, pluskvamperfekt, futurum
- **Passive** forms
- **Reflexive** verbs (sig, sin, sitt, sina)
- **Particle verbs** (ta upp, gå ut, komma in)

## 7. Additional Grammar

Examples should also demonstrate:

- Negation — *inte* placement
- Inversion — word order changes
- Bisatser — subordinate clauses
- Relativsatser — relative clauses
- Jämförelser — större än, bättre än
- Räkneord — numbers
- Possessiva pronomen — min/mitt/mina, sin/sitt/sina

---

## 8. Text Types (Texttyper)

Show the word in different writing styles:

| Style | Swedish name |
|-------|-------------|
| Narrative | Berättande |
| Descriptive | Beskrivande |
| Explanatory | Förklarande |
| Argumentative | Argumenterande |
| Report | Rapport |
| Instruction | Instruktion |

## 9. Level Progression

Write examples at increasing difficulty:

**SFI C → SFI D → SVA 1 → SVA 2 → SVA 3**

Rewrite the same idea in simpler and then more advanced forms.

## 10. Real-Life Context

Show how the word behaves across:

- **Situation** — home, school, work, society
- **Time** — past → present → future
- **Register** — formal vs informal

---

## 11. Practice

Exercises in progressive difficulty (easy → medium → advanced):

- Combine clauses, particles, and multiple verbs
- Include questions, statements, and relative clauses

### Preferences

- Many example sentences
- Natural spoken Swedish
- Always include: *den som*, *mitt*, *nu*, *klar*, *ta*
- Compare: this / that / there / they / their
- Include English cues
- Show alternative sentence patterns for the same idea

---

## Summary

The full learning path for one word:

```
WORD → NETWORK → GRAMMAR → SENTENCES → TEXT TYPES → LEVELS → PRACTICE
```
