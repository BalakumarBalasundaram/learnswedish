# verb med papper
- exempel: Lyft, Lägg ner, Vänd, Snurra, Rulla ihop, Rulla ut, Vik, Skrynkla, slät ut, Riv, Blås.
- exempel meningar:
1. Lyft papperet försiktigt så att det inte går sönder. -> Lift the paper carefully so it doesn't tear.
2. Lägg ner papperet på bordet innan du börjar skriva. -> Lay the paper down on the table before you start writing.
3. Vänd papperet för att skriva på andra sidan. -> Turn the paper to write on the other side.
4. Snurra papperet för att skapa en rulle. -> Roll the paper to create a roll.
5. Rulla ihop papperet för att förvara det lättare. -> Roll up the paper for easier storage.
6. Rulla ut papperet på golvet för att mäta längden. -> Roll out the paper on the floor to measure the length.
7. Vik papperet på mitten för att göra ett kort. -> Fold the paper in half to make a card.
8. Skrynkla papperet för att skapa en textur. -> Crumple the paper to create a texture.
9. Slät ut papperet för att ta bort veck. -> Smooth out the paper to remove wrinkles.
10. Riv papperet i små bitar för att göra konfetti. -> Tear the paper into small pieces to make confetti.
11. Blås bort dammet från papperet innan du använder det. -> Blow off the dust from the paper before using it.
